# Prompt Master

Mod do Claude Code que acrescenta um botão **✨ Melhorar prompt** por cima da caixa de prompt
(e o comando `/prompt-master`). Escreves o pedido como te sair, carregas no botão e o Claude:

1. analisa o rascunho segundo 6 blocos — Papel, Objetivo, Contexto, Tarefa, Restrições,
   Formato e critério de conclusão;
2. pergunta-te só o que falta (máx. 4 perguntas, com opções);
3. devolve o pedido reescrito diretamente à caixa de prompt, para reveres e enviares.

O pedido original não é executado. `/prompt-master <texto>` faz o mesmo com o texto dado.
